# QuickExit v0.11 — Premium Markets Experience

Local review build. No commit, push, deployment, hosted settings change, or hosted database verification was performed.

## Experience

Markets now has the requested headline, a lightweight CSS globe, mint calls to action, three featured markets, a searchable explorer with movement filters and sorting, and a compact portfolio/checklist panel. Desktop uses a right-hand panel; tablet adapts to two panels below the explorer; mobile uses stacked market cards and portfolio controls. Existing navigation, typography, theme, EUR formatting, portfolio calculations and Coinbase integration are reused.

Only BTC, ETH and SOL appear. Prices, percentage changes and candles come from the existing Coinbase providers. Stale/error/offline observations retain their existing labels; movement filters and sorting use fresh verified observations, with unavailable values last. No market-cap, volume, aggregate market statistics, unsupported assets, fabricated chart, or new dependency was added.

Demo portfolios are labeled DEMO / LOCAL; authenticated portfolios are labeled CLOUD / SIMULATED. An uninitialized cloud account displays no portfolio value or proposed cash as an existing balance. The header and Home/Cash Out balance displays are also gated while account data is unavailable. Existing confirmation controls remain inside the starting-portfolio action. Rendering and navigation do not invoke creation/import; cancellation preserves the uninitialized account.

## Limits

The reference globe is interpreted with lightweight CSS rather than a photo. There are only three supported markets. Portfolio history is not invented; the panel displays existing calculated metrics rather than the mockup's speculative chart. Current market observations can change between captures. Hosted Account A session/data verification remains pending; its prepared SELECT-only query was not executed. All trades and transfers remain simulated. The local review server uses the existing disabled account/registration gates; it does not enable hosted sign-in for this design review.
