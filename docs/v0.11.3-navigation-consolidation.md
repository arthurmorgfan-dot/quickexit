# QuickExit v0.11.3 — Navigation and portfolio consolidation

Local work awaiting review; earlier uncommitted refinements are preserved.

## Changes

Primary desktop and mobile navigation now contains Markets, Trade, Portfolio, History and Cash Out; desktop also retains Settings. The header workspace shortcut opens Markets. Both authenticated and Demo sessions default to Markets through the same existing authentication initialization. No authentication mode is selected by navigation.

Portfolio consolidates the previous Home financial summary: total simulated value, cash, invested capital, separately labeled realized and unrealized net P&L, simulated transfers, recorded-exit performance and active positions. Capital allocation uses existing cash/invested principal and does not invent historical valuations. Existing portfolio-summary and performance calculations are reused. Trading, history and simulated-transfer actions remain available for initialized portfolios only.

History reuses completed-position, receipt, journal and activity components. The duplicate Home recent-activity widget is removed; Trade retains its compact contextual activity preview with a link to History. Markets retains discovery and its compact onboarding/portfolio panel.

The previous Home was an internal view, not a separate page route. View query aliases Home/Positions resolve to Portfolio and Activity resolves to History. A compatibility /app/home route opens /app?view=Portfolio. Only an explicitly requested demo=1 is carried through; the redirect never selects Demo implicitly. Search-param rendering and redirect components use Suspense loading states required by the installed Next.js version. Unresolved/uninitialized Portfolio and History show account-state guidance without rendering guest balances or records. v0.11.2 observer/event ordering and restoration locks are unchanged.
