# QuickExit v0.11.4 — Responsive UX Refinement

Local presentation changes based on the v0.11.3 visual review:

- Markets removes decorative hero copy that overlapped at tablet widths, wraps featured timeframe controls, and reports unavailable history once per chart.
- Trade replaces six portfolio metrics with a simulated cash/position summary. Mobile and tablet show the order form before market details, with the document order matching the compact layout; empty history is compact while observed charts retain their existing rendering.
- Portfolio leads with total simulated value, removes the duplicate header balance and trade action, shows allocation percentages without repeating cash amounts, clarifies simulated valuation copy for active Demo positions, and reduces empty performance spacing.
- History uses the full available width and adds spacing before activity.

Authentication restoration, initialization confirmation, order execution, fees, receipts and journal logic were not changed. Account access and registration remain disabled in the local Demo review build.

Validation: 178 tests passed, TypeScript, ESLint, production build and diff whitespace checks passed. Added regressions for factual empty and populated performance and compact Demo market presentation. The optional `tests/responsive-refinement-browser.mjs` validates fresh local fixtures using the production snapshot decoder. At 390, 768 and 1440px it captures all four pages both before user trades and with a completed BTC trade plus an active ETH position (24 page captures and three actual Demo receipt captures). Built-in illustrative examples remain present in the pre-trade History state because the production decoder restores them. Search, sorting, unavailable-data filters, featured timeframe selection, active navigation, the confirmation/back flow, recorded performance charts, receipt opening/return and local journal saving passed. All market requests were intercepted locally; all external requests were blocked. No browser application errors or external requests were observed. No page-wide horizontal overflow or featured timeframe overflow was detected. Captures are retained locally in `docs/screenshots/v0.11.4`, with working copies in `/private/tmp/quickexit-v114-review`.

Limitations: no hosted authentication/session test or cloud portfolio operation was performed. The visual pass covers Demo balances, active/completed trades and unavailable market data. Populated provider charts rely on existing regression coverage; no live provider was contacted. Receipt return navigation was verified, but automatic keyboard-focus restoration was not reliably established during this pass.

## Repeatable local visual review

Run the optional browser suite with the existing external Playwright installation:

```sh
QUICKEXIT_BROWSER_MODULE=/private/tmp/quickexit-browser/node_modules/playwright/index.mjs node tests/responsive-refinement-browser.mjs
```

The server must use account access and registration disabled. The suite accepts loopback URLs only. It uses fresh browser contexts and production-valid Demo snapshots; no existing browser session is inspected or changed.
