# QuickExit v0.11.7 — Navigation and History review

Local implementation ready for owner review; no commit or deployment.

## Changes

Section changes previously updated component state without updating the URL, so reload used the landing default. Portfolio is now the default when no valid section is supplied. Navigation writes `view` into the current URL using the native History API, preserving Demo selection, other query parameters and fragments. A React external-store subscription reads that URL and handles popstate and local section changes. Reload, direct links and browser back/forward therefore use the same section source. Legacy Home/Positions/Activity mappings remain intact.

Navigation does not read or modify authentication, portfolio storage or cloud transport. Existing authentication restoration and uninitialized-account guards remain in place; no redirect or automatic initialization was added. No active account session was used for testing.

History's overview uses less padding and vertical space with stronger realized P&L weight. Table rows are slightly tighter while receipt controls retain their dimensions. The prior readable explanatory text, tablet grid and compact mobile metrics remain. Financial calculations, actual/example distinction, journal logic and receipt focus behavior are unchanged.

Changed implementation: `src/lib/workspace-navigation.ts`, `src/components/workspace/Workspace.tsx`, `src/app/app/workspace.css`, and v0.11.7 public build metadata. Tests updated in `workspace-navigation.test.mjs`, `trading-history-browser.mjs` and `secure-accounts.test.mjs`.
