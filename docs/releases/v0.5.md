# QuickExit v0.5 — Market Intelligence

Production release checkpoint. Commit/push and the existing Vercel deployment are authorized for this release; no migrations or production database changes are included. All trades, balances and transfers remain simulated. Hosted accounts remain gated off until database/security verification and explicit activation.

## Stages delivered

1. Read-only market foundation: provider-neutral server contract, normalized EUR quotes/statistics/OHLCV, bounded process cache, coalesced requests, serialized provider requests, failure cooldown, retry and stale fallback.
2. Interactive charting: TradingView Lightweight Charts 5.2.1, line/candlestick series, 1H/4H/1D/1W/1M/1Y ranges, real price/time axes, crosshair inspection, accessible price list, attribution and responsive resize handling. Chart type changes retain the asset/timeframe and do not fetch data again. Mobile keeps charts behind the established disclosure; profit remains primary.
3. Paper integration: the existing Live quote watcher now reads the same server quote adapter. Only non-stale validated quotes reach the unchanged execution store. Statistics/history never drive entries, valuation or exits. Confirmation guards, fixed entries, centralized costs, protection, observed-price automatic exits, completed receipts/history and guest persistence remain intact.

## Data provider and limitations

Coinbase Exchange's public GET-only product endpoints are used for BTC-EUR, ETH-EUR and SOL-EUR (all currently supported assets). No key, account, wallet or authenticated endpoint is used. The interface reports venue-specific 24h high/low/change and **base-asset volume**, not worldwide volume or fabricated EUR turnover. Change is last versus the venue's 24h open. Quote time is the latest observed trade, not the cache retrieval time. [Statistics](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-stats).

Candles use provider OHLCV and supported granularity. Ranges are: 1H/1-minute, 4H/5-minute, 1D/15-minute, 1W/hourly, 1M/6-hour, 1Y/daily. Requests are bounded to 300 bars; the year range pages twice and deduplicates the shared boundary. Missing bars, including absent range edges, are counted and never interpolated. Empty history produces an explicit unavailable state. The latest candle may still be forming. [Historical API limits](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-candles).

Quotes poll every 30 seconds through the existing watcher; statistics/history refresh each minute while the market card is mounted. Server TTLs: quotes 15s, statistics 60s, short history 60s, other history 300s. Last-known quote/stat results may be retained for one hour, history for one day, always marked stale on failed refresh; stale results never become fresh trade inputs. Browser quote validation still requires a trade observation within two minutes (10-second future tolerance). Labels: Live ≤45s, Delayed 45–120s, Stale beyond 120s or provider unavailable, Unavailable with no observation. A Demo reference is explicitly labeled when Live has no usable quote.

Public REST limits are IP-based; this adapter serializes requests with a 120ms spacing, makes at most two attempts on transient failures, respects bounded numeric/HTTP-date Retry-After, and avoids retrying ordinary 4xx errors. Request coalescing and per-key failure cooldown prevent same-process storms. [Provider rate limits](https://docs.cdp.coinbase.com/exchange/rest-api/rate-limits).

**Costs:** no paid subscription or provider credential is required by these public endpoints. Hosting/network costs remain usage-dependent; no service level or unlimited traffic is promised. Lightweight Charts is Apache-2.0 with TradingView attribution retained in both the chart and visible notice/link. [Chart licensing](https://github.com/tradingview/lightweight-charts).

## Architecture

- `src/lib/market/{models,service,client,api}.ts`: shared types/validation, replaceable provider and bounded cache, same-origin read-only client, allowlisted HTTP handler.
- `/api/market`: quote, stats, history resources only; asset/timeframe allowlists, no user data or execution, safe errors and Retry-After.
- `useMarketIntelligence.ts`, `PriceChart.tsx`, `MarketCard.tsx`: cancellable independent statistics/history requests, dynamic client-only chart import, disclosures/status/readable statistics.
- `usePersistentDemo.ts`, `Workspace.tsx`: existing paper quote watcher integration and market state props. Financial engine files and paper schema are unchanged.
- Scoped `workspace.css` additions preserve existing layouts/tokens. `package.json`/lock add only Lightweight Charts and its canvas dependency.
- `tests/market-intelligence.test.mjs`: normalization, invalid data, rate limits/retry, gap/empty history, year paging, cache/coalescing, stale/missing quote rejection, API allowlists/errors and chart projections.
- `tests/market-browser.mjs`: optional automated browser suite using deterministic intercepted market responses; no external provider or Supabase writes.

## Remaining risks

- Cache/queue are process-local, not distributed. Multiple serverless instances share provider IP limits unevenly; production scale needs a shared cache/rate limiter and operational monitoring. No load-test was performed; deployment verification is reported separately.
- Quotes are polling-based, not streaming. Venue outages, thin EUR markets, sleeping browser tabs and clock skew can delay observations. Automatic paper exits evaluate observed updates, not guaranteed prices or continuously running exchange orders.
- Quote batches remain atomic across all three assets, preserving existing store behavior; one unavailable asset holds the batch. Last-known financial state is retained and new stale Live entries are blocked.
- Historical gaps, limited venue history, mutable in-progress candles and stale cache are disclosed. Historical chart values never retroactively alter receipts.
- Dependency audit reports five pre-existing high-severity findings in the ESLint tooling dependency chain; none is in the added chart library. The suggested fix downgrades ESLint's Next configuration to a different major release and was not applied. Review the tooling chain separately.
- Hosted authentication, Supabase migrations, RLS integration, real accounts and cross-device sync remain unverified/disabled. No production database was accessed.
