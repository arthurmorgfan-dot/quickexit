# v0.11.6 — Final History polish

Ready for owner review; not committed or deployed.

Only `src/app/app/workspace.css` changed for this pass. History explanatory text increases from the inherited 8px to 12px, with clearer color, line height and left alignment. Filter labels increase to 12px. Tablet uses a three-column grid: Records/Asset/Result, then From/To/Clear. Mobile preserves all three performance metrics in one row, reduces overview spacing and allows Records to share a filter row. Controls have a minimum 44px height. Financial logic, records, authentication and journal/receipt behavior were not changed.
