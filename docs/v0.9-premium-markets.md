# QuickExit v0.9 — Premium Markets

Local redesign preserves the existing sidebar, paper-trade navigation, onboarding,
account gates and accounting. The earlier uncommitted v0.8 read-only verification
files are retained; no Supabase migrations or hosted configuration changed.

Markets now has the requested heading/subtitle, an honest aggregate freshness
indicator, EUR label, BTC/ETH/SOL featured cards, observed candle-close sparklines,
range controls, search, All/Gainers/Losers filters, and a responsive semantic market
table. Trade uses the existing onSelect handler and centralized execution engine.
Shared asset marks use recognizable Ethereum and Solana vectors; Markets applies
compact colored icon treatments, restrained movement colors and mint actions.

Ranges are 1H, 1D, 1W, 1M and 1Y using existing genuine Coinbase Exchange candle
windows. Longer windows use the existing provider pagination. No candles, gaps,
prices, movement or global statistics are synthesized. The table always shows
24-hour history; changing a card range does not change the table or selected asset.
Missing/sparse history is labeled unavailable; missing intervals break SVG paths.
Chart direction reflects the selected observed range, not an invented 24h trend.

Quotes refresh every 30 seconds through the existing server cache. Stats and
histories reuse the tab-local intelligence reader and server cache/cooldowns;
returning to a range reuses validated observations. The default 1D card/table data
is shared. Range switching does not start a separate quote poll. Offscreen-tab
range history polling pauses through the existing hook. Default Markets polling
retains the existing 30-second schedule and aborts when unmounted.

Prices have timestamp/freshness labels. Aggregate “Live” requires all three fresh
quotes. Offline/error/stale data is never labeled live; unverified 24h changes are
hidden and excluded from movement filters. Last known history remains explicitly
labeled. Provider outages and rate limits can leave a market unavailable. All
trades/balances remain simulated, and stale fill protection remains unchanged.

Market capitalization, BTC dominance, and global volume insights are omitted:
there is no trustworthy existing source for these metrics. The source footer
states the factual supported-market count. XRP/ADA/DOGE remain unsupported.
Safe build metadata now labels the local application version 0.9; dirty builds
continue to identify their base commit rather than claiming a new checkpoint.

Validation: TypeScript, lint, production build and 154 automated tests passed.
Four new tests cover movement freshness/filtering, timestamp/gap preservation,
history freshness and SSR/accessibility/empty component rendering. Browser checks
passed at 320, 390, 768 and 1440px with genuine Coinbase history, card range changes,
search/filters, offline changes, keyboard Trade navigation and refreshed selected
asset. No overflow or runtime errors. Existing onboarding, feedback, reset
cancellation, offline and journal/chart persistence regression checks passed at
all four widths. Screenshots visually reviewed at all four widths. Existing trading-chart types,
intervals, crosshair, panning, touch and preference persistence also passed.

Repeat optional browser verification against the running local production build:
`QUICKEXIT_BROWSER_MODULE=/absolute/path/to/playwright/index.mjs node tests/markets-browser.mjs`.
No browser dependency was added to the application; screenshots use the system
temporary directory. This check requires actual Coinbase data availability and
reports failure rather than replacing unavailable data with fixtures.

Hosted v0.8 authentication verification remains incomplete. Accounts stay off.
No commit, push, deployment, hosted mutation or account enablement is authorized
by this local implementation phase.
